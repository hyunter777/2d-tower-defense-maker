Class LevelPlay

Namespace
TDMaker.Editor
Assembly
TDMaker.Editor.dll

"Play this level": saves, opens the saved scene that plays the level (or a temporary unsaved scene with the game rig when no scene does) and enters Play mode. When Play mode stops, the scenes that were open before are opened again. Modelled on UnitSandboxPlay (same scene capture and restore); nothing is written to disk except the saves the user agrees to.
