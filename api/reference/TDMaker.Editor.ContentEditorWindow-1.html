2D Tower Defense Maker API

Class ContentEditorWindow<TAsset>

Namespace
TDMaker.Editor
Assembly
TDMaker.Editor.dll

Shared frame of the per-type content editors: header, toolbar (search, New, Duplicate, Delete, Ping), a list of every TAsset in the project, a form bound to the selected asset (so Undo and saving are Unity's own), an optional preview column (hidden below 980 px) and a live check line.

public abstract class ContentEditorWindow<TAsset> : EditorWindow where TAsset : ScriptableObject
