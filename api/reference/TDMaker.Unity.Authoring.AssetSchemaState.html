Where an asset stands relative to the running code's schema.

public enum AssetSchemaState

Fields

Current = 1

Saved with the current schema (or freshly created and stamped when first saved).

NewerThanSupported = 3

Saved by a newer version of the package. Left untouched; never migrated or stamped down.

Outdated = 2

Saved with an older schema. It is migrated in memory on load; Upgrade(Object) stamps it so a save writes the new version.

Unversioned = 0

The asset does not implement IVersionedAsset.
