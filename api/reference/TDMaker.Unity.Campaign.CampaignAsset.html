Class CampaignAsset

Namespace
TDMaker.Unity.Campaign
Assembly
TDMaker.Unity.dll

A campaign: ordered levels on a world map with unlock rules (previous level, a list of required levels, an optional star gate, side branches that never block the main path) and the map picture. Progress lives in a save slot (ProfileData, read through CampaignProgress); this asset only describes the campaign. Edit it in the inspector: click in the map view to place level points, and the inspector lists validation problems.
