Class CampaignMapScreen

TDMaker.Unity.Campaign

World map screen built from code (uGUI + TextMesh Pro, styled by a HudTheme): the campaign's map picture with a point per level (locked with a lock, open with its number, completed with its best stars), dashed roads from each level's prerequisites, the star total, and a level info panel (title, summary, best stars, unlock requirements, Play). Call Show(CampaignProgress, CampaignMapUpdate) with the slot's progress and the update returned by ApplyPending() to highlight new stars and newly opened levels. PlayRequested and BackRequested leave the screen to the caller. Keys: 1-9 select a level, Enter plays it, Esc closes the panel and then goes back. Texts use HudTexts keys and relabel when the language changes. When the campaign has an upgradeShop, a Shop button (with the unspent stars as a badge) opens the UpgradeShopScreen over the map.
