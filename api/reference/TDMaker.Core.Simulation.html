public ulong ComputeStateHash()

Returns

ulong

Examples

Remarks

Use identical definitions, extension registration and seed. Extensions must contribute their mutable state via IStateHashContributor. Exact floating-point bits diagnose same-runtime divergence; this is not a cross-platform numeric determinism guarantee.
