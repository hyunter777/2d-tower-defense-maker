Class TDCameraController

Namespace
TDMaker.Unity.View
Assembly
TDMaker.Unity.dll

Orthographic 2D camera for a level: frames the level on start using the level's CameraFramingData (fit the whole map, fit its height or width and scroll, or a fixed view size; start focus and optional intro pan) at any aspect ratio, and optionally pans (screen edge, middle-mouse drag, WASD/arrows, left drag from empty ground) and zooms (mouse wheel, +/-), always clamped to the bounds. Toggles live in TDGameSettings.
