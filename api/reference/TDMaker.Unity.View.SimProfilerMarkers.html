Class SimProfilerMarkers

Namespace
TDMaker.Unity.View
Assembly
TDMaker.Unity.dll

Core profiling hook that wraps every fixed step and every pipeline stage (system) in a Unity Unity.Profiling.ProfilerMarker, so the Unity Profiler shows TDMaker.Sim.Step with one child marker per stage (TDMaker.Sim.Motion, TDMaker.Sim.Ranged, ...). Another ISimProfiler can be chained through Next; it receives every callback after the marker begins and before it ends.

Remarks

Installed by SimulationRunner in builds with the profiler enabled (editor and development players). Marker Begin/End compile away in non-development players. Allocates only the first time a new system index is seen. Built-in stages are named after SimStage; registered custom systems are named TDMaker.Sim.<anchor stage>#<pipeline index>.
