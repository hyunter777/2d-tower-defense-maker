2D Tower Defense Maker API

Class SampleAudio

Namespace
TDMaker.Editor
Assembly
TDMaker.Editor.dll

Assigns the optional sample audio (Assets/TDMaker/Samples/Audio/Sfx/<key>.ogg and Music/<key>.ogg) to sample cues by key. A missing file leaves its cue empty, so sample generation is deterministic with or without the audio. The key tables are public so tests (and buyers copying the scheme) can check them.
