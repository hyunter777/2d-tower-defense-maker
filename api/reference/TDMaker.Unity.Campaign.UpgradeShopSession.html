Class UpgradeShopSession

Namespace
TDMaker.Unity.Campaign
Assembly
TDMaker.Unity.dll

One visit of the star-upgrade shop over a save slot. Every rule comes from the core UpgradeShopRules: only the next rank of a track can be bought and only with enough stars (Available = EarnedTotal − Spent); opening the session copies the purchases as the revert baseline; Revert() returns to that baseline (not one step back); ResetAll() clears every purchase and makes the cleared state the new baseline. Each change is written into the slot's ProfileData (ranks per track key and stars spent) and saved at once through Save.
