SimRandom

A reproducible xorshift32 random stream; zero seeds are remapped.

A deterministic fixed-step world. Use commands for player actions and ClearEvents after reading output.

SimulationClock

A bounded frame accumulator implementing the product catch-up policy without engine dependencies.

SpatialQueryBuffer

Caller-owned fixed-capacity query storage. Entries are valid until this buffer is queried again.

TrapBinding

Pooled deployment state, valid only while present in Simulation.Traps; retain Id across removals.

UpgradeShopRules

Storage-independent immutable star-shop transitions. Forced battle ranks never affect spending.

Structs

Allocation-free snapshot of calling the next wave now; obtaining it does not mutate the simulation or emit events.

A value event. Value is damage or state total; IntValue is a slot, wave, or state delta.

Interfaces

Optional persistence for custom commands. Type IDs 1024 and above belong to applications.

Handles an exact custom command type without reflection or dynamic dispatch generation in the tick.

ICustomComponent

A prewarmed custom component; its reset must not allocate.

IDamageHook

Damage hooks run in registration order. Implementations must not allocate or recursively request damage in BeforeDamage.

ISimProfiler

Optional observational profiling hooks. Preallocate storage, avoid allocation, and do not mutate the world from callbacks.

IStateHashContributor

Optional deterministic state hashing for custom components, commands, systems, and other extension state.

ITargetSelector

Optional ranged target selection. Return null to decline an attack; use Simulation.FindDefaultTarget for fallback rather than recursively calling FindTarget.
