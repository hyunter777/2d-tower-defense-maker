TDMaker.Editor.dll

Inspector of CampaignAsset: a map view of the world map picture with the level points and their unlock roads (arrows from prerequisites, dashed for branches, red for problems). Click a point to select it, drag it to move it, click an empty spot to move the selected point there, drop Level assets on the map to add them, right-click a point for more. Below: the ordered level list, the selected level's settings and the validation results. Every edit is undoable.
