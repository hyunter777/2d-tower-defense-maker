An authored asset that carries a serialized schema version and takes part in AssetSchema migrations.

public interface IVersionedAsset

Remarks

Every built-in content asset implements this. To version your own standalone UnityEngine.ScriptableObject:

  1. add [SerializeField, HideInInspector] private int schemaVersion; with no initializer (it must read 0 on old files) and implement SchemaVersion over it;
  2. implement UnityEngine.ISerializationCallbackReceiver and call HandleBeforeSerialize(IVersionedAsset) and HandleAfterDeserialize(IVersionedAsset) from it;
  3. register steps with RegisterStep<T>(int, Action<T>) from the type's static constructor.

For a subclass of a built-in base (for example TemplateExtensionAsset), implement ISubclassVersionedAsset instead; the base already handles the callbacks.

Properties

SchemaVersion

Schema version of the serialized data. 0 means "written before versioning" (1.0 data) or "made in code and not yet stamped"; do not edit it by hand.
