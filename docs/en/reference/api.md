# Public API reference

The <a href="../../api/index.html">generated API reference</a> documents the public C# types and members in the package's three assemblies:

- **TDMaker.Core** — Unity-independent simulation, templates, commands and deterministic rules.
- **TDMaker.Unity** — authoring assets, views, HUD, campaigns, localization and runtime integration.
- **TDMaker.Editor** — maker tools, validation, sample generation and online documentation entry points.

Start with [Core concepts](../concepts.md) for the data flow or [Extending the framework](../extending.md) for integration examples. The product name is **2D Tower Defense Maker**; the C# namespaces remain `TDMaker.*`.

The reference is generated from the package code. Unity and .NET types used in signatures belong to their respective platforms. Assembly binaries and the package implementation are not distributed with this documentation site.
