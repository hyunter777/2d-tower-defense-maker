Class JsonFileSaveStore

Default store: one JSON file per slot under UnityEngine.Application.persistentDataPath (folder TDMakerSaves, files slot1.json, slot2.json, ...). Writes go to a temporary file that then replaces the slot file, so a crash mid-write leaves the previous save intact. An unreadable file is renamed to slotN.json.bak (or .bak2, ...) and kept. Not for WebGL (use PlayerPrefsSaveStore, or CreateDefault(int, string)).
