Interaction state. Spell aiming is tracked separately (AimingSpell) and always runs in Browsing.

public enum GameHud.Mode

Fields

Browsing = 0

Nothing selected.

BuildMenu = 1

Build options of an empty slot are open.

HeroSelected = 4

A hero is selected; every battlefield click is a move attempt at that point.

RallyAiming = 3

Choosing a barracks rally point (the tower stays selected, its panel is hidden).

TowerMenu = 2

A tower's panel is open.

UnitSelected = 5

An enemy or soldier is inspected (information only, not an attack order).
