Class RangeShape

TDMaker.Unity.dll

The single source of the range ellipse used by every view, gizmo and editor preview. It matches the simulation (Simulation.RangeDistanceSquared): a point is inside when dx²/r² + dy²/(k·r)² ≤ 1 (boundary included), with k = range Y scale. The horizontal semi-axis is r and the vertical semi-axis is k·r, so k < 1 flattens the ellipse vertically (an oblique top-down look).
