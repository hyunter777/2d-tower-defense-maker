Class SaveSlotScreen

Namespace
TDMaker.Unity.Campaign
Assembly
TDMaker.Unity.dll

Save slot picker built from code (styled by a HudTheme): one row per slot of a CampaignSaveSlots with its stars, levels won and last play time, a Continue / New Campaign button and Delete (with a confirmation dialog: Delete, Cancel). One click on a slot opens it (SlotChosen); a new slot needs no name or extra confirmation. Keys: 1-9 choose a slot, Esc cancels the dialog and then goes back. Texts use HudTexts keys.
