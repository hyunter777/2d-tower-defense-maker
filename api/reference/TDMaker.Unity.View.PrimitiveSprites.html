Class PrimitiveSprites

Namespace
TDMaker.Unity.View
Assembly
TDMaker.Unity.dll

Procedurally generated sprites (1 world unit across) so samples work with zero imported art. Every shape exists as a flat white silhouette and as an outlined, top-lit grayscale version; both are tinted by the renderer colour. Shapes are described by signed distance functions in unit space (-0.5..0.5, y up).
