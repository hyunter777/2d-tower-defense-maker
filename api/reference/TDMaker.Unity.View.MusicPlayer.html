2D Tower Defense Maker API

Class MusicPlayer

Namespace
TDMaker.Unity.View
Assembly
TDMaker.Unity.dll

Plays background music: a menu loop while no battle is shown, the level's battle loop (music, falling back to this component's defaults), an optional intense loop from configurable waves (last wave, waves flagged bossWave, or from a wave number) and victory / defeat stingers that stop or duck the loop. Changes crossfade between two pooled AudioSources; a third plays stingers. Volume = track × TDGameSettings Music × Master, routed to the Music mixer group when one is set. No allocation per frame; every clip is optional (an empty slot is silent).

[AddComponentMenu("2D Tower Defense Maker/Music Player")]
public sealed class MusicPlayer : MonoBehaviour
