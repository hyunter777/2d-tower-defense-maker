Class TrapData

Namespace
TDMaker.Unity.Authoring
Assembly
TDMaker.Unity.dll

A fixed-position deployment (mine, snare, glyph) placed by an ability action, baked into TrapDef. It arms after a delay, then hits the nearest eligible unit inside its detection radius until its triggers or lifetime run out. Use it as an ability action (useTrap).
