Fixed-capacity input recording with seed and versioned binary persistence. Record only external Enqueue calls between ticks.

Examples

var log = new CommandLog(sim.Seed); sim.StartRecording(log); /* enqueue and step */ sim.StopRecording(); log.WriteTo(stream);

Remarks

Recreate identical templates, initial spawns and extensions before replay. Commands generated inside Step are regenerated by their systems. Saving and loading allocate outside Step; custom commands require an ICommandCodec.
