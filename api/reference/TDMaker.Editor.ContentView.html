Class ContentView

Namespace
TDMaker.Editor
Assembly
TDMaker.Editor.dll

The Content page of the Project Overview: every maker asset in one list (filter by kind, search by name or folder, show only assets with problems), and for the selected asset its project check problems, the maker assets that use it and that it uses, and buttons to open it in its editor, select it in the Project window or play it (levels).
