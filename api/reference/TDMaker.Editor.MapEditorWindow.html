Class MapEditorWindow

Namespace
TDMaker.Editor

TDMaker.Editor.dll

Map Editor (Tools > 2D Tower Defense Maker > Map Editor): turns a painted map into a level. Drop a sprite or texture as the background (the camera bounds fit it), draw smooth curved paths with a few clicks, place build slots with automatic rally points, set where each entrance's wave-call button appears, then Validate, Dry Run and Bake — all with Undo and in the Scene view (2D).
