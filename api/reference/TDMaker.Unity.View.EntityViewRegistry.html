2D Tower Defense Maker API

Class EntityViewRegistry

Namespace
TDMaker.Unity.View
Assembly
TDMaker.Unity.dll

Creates, pools and updates EntityViews from simulation events. Prefabs come from authoring assets or the TDMaker.Unity.View.EntityViewRegistry.overrides list (by view key); otherwise generated primitive sprites are used. Also routes per-template presentation hooks (VFX prefabs through VfxPool, audio cues through AudioCuePlayer) and draws built-in feedback: impact flashes, splash rings and instant-hit beams.
