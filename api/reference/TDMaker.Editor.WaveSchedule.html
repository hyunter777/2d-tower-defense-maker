Class WaveSchedule

Namespace
TDMaker.Editor
Assembly
TDMaker.Editor.dll

Mirrors the simulation's spawn schedule: a group's entries run back to back; an entry entered at s with start delay d, interval h and count n spawns at s+d+h … s+d+nh, waits one more interval, then the next entry is entered after the following gap.
