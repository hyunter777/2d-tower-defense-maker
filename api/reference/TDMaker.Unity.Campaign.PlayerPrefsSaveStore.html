Class PlayerPrefsSaveStore

Namespace
TDMaker.Unity.Campaign

TDMaker.Unity.dll

Store in UnityEngine.PlayerPrefs (browser storage in WebGL builds): one string per slot under prefix + slot number. Unreadable content is copied to key.bak before the slot is cleared. Flushes with UnityEngine.PlayerPrefs.Save() on every write.
