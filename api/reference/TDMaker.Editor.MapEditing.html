Class MapEditing

Namespace
TDMaker.Editor
Assembly
TDMaker.Editor.dll

Undoable level-authoring operations behind the Map Editor (and usable from your own editor scripts): edit points of curve and polyline paths, create/delete/duplicate/align build slots with automatic rally points, path order, painted background setup and baking scene geometry into a LevelAsset.
