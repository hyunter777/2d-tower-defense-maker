Class ReviveData

Namespace
TDMaker.Unity.Authoring

Same-unit return on the spot, baked into a ReviveDef (template custom data): a killed unit lies down, then gets returnShare of its health back, rises and walks on with the same identity. Its bounty is paid once, on the first death. Pending returns hold victory.
