Class EllipseRenderer

Namespace
TDMaker.Unity.View

TDMaker.Unity.dll

A smooth range ellipse: a filled mesh plus an outline line. Its shape always comes from RangeShape, the same ellipse the simulation uses for range checks, so what is drawn is what is hit.
