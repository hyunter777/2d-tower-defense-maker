SampleCurve(IReadOnlyList<Vector2>, float, List<Vector2>, List<int>, List<float>)

Samples a smooth centripetal Catmull-Rom curve through controls into nodes about nodeSpacing apart (measured along the curve). Every control point is emitted exactly as a node, so the curve passes through them; each span gets max(1, round(length / spacing)) equal arc-length steps.

public static void SampleCurve(IReadOnlyList<Vector2> controls, float nodeSpacing, List<Vector2> output, List<int> controlNodes = null, List<float> spanFractions = null)

Parameters

controls IReadOnlyList<Vector2>

Control points, from entry to exit.

nodeSpacing float

Target distance between nodes.

output List<Vector2>

Receives the nodes (cleared first).

controlNodes List<int>

Optional: receives the node index of each control point.

spanFractions List<float>

Optional: receives, per node, its span index plus the arc-length fraction within the span.
