2D Tower Defense Maker API

Class SimulationRunner

Namespace
TDMaker.Unity.View
Assembly
TDMaker.Unity.dll

Owns a Simulation and advances it with the core SimulationClock from Update (catch-up limit = catch-up ticks × speed per frame). Events produced during a frame are dispatched in emission order through EventRaised and then cleared, so the event buffer (Event Capacity) must hold every tick a frame catches up (at most catch-up ticks × speed). Commands queued after the game ended are rejected by the core with GameEnded on the next frame (the clock no longer steps, so the runner flushes them).
