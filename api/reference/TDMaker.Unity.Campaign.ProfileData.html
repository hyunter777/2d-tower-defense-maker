Class ProfileData

Namespace
TDMaker.Unity.Campaign

Everything one save slot stores: opened levels with best stars, victories not yet merged into the map, purchased permanent upgrade ranks per track, stars spent on them, and free game-specific entries. App settings (volumes, language) are not part of a slot; they stay in TDGameSettings. Serialized with UnityEngine.JsonUtility by ProfileSerializer; version drives migrations.
