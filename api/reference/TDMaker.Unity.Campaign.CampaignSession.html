Class CampaignSession

Namespace
TDMaker.Unity.Campaign
Assembly
TDMaker.Unity.dll

The save slots whose slot is open right now (set by Open(int)). A SimulationRunner reads the open slot's purchased upgrade ranks and its campaign's upgradeShop from here when a battle starts, and the upgrade shop saves through it, so a flow script needs no extra wiring. Cleared when play mode starts.
