Class UpgradeShopScreen

Namespace
TDMaker.Unity.Campaign
Assembly
TDMaker.Unity.dll

The permanent star-upgrade shop, built from code (uGUI + TextMesh Pro, styled by a HudTheme) over the world map: one column per track with its rank nodes, the stars to spend, a tooltip on hover (price, state and an effect summary generated from the data), one click on the next affordable rank buys it at once (no confirmation), Undo Changes returns to the purchases the shop opened with, Reset All clears every purchase (no confirmation) and Done or Esc closes it. Every change is saved immediately (UpgradeShopSession). CampaignMapScreen opens it from its Shop button.

[AddComponentMenu("2D Tower Defense Maker/Campaign/Upgrade Shop Screen")]
