Class UnitFrames

Namespace
TDMaker.Editor
Assembly
TDMaker.Editor.dll

Bulk frame registration for the Unit Workshop: sorts sprite files into walk / idle / attack / hurt / death sequences by file name ("Orc_Walk_003", "walk (2)", "1_ATTACK_005", "goblinRun07", "Hit1"), fixes their texture import settings (single sprite, pivot at the feet, compressed) and writes the sequences into an ArtSet.Entry. Facing is never guessed; the author ticks Faces Left.
