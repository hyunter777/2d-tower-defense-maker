Class PathAuthoring

Namespace
TDMaker.Unity.Authoring
Assembly
TDMaker.Unity.dll

Scene authoring for an enemy path. Points are in local space; sub-lanes are generated from the center line using laneCount and laneSpacing. In curve mode (curve) the user edits a few controlPoints and points is regenerated as a smooth curve sampled every curveNodeSpacing units (see RebuildFromCurve()).

[AddComponentMenu("2D Tower Defense Maker/Path Authoring")]
