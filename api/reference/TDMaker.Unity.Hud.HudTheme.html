Look of the production HUD and of the world-space feedback (ranges, rally, aim). Every sprite slot is optional: empty slots use generated sprites from HudSprites. Create one with Assets/Create/2D Tower Defense Maker/HUD Theme and assign it to GameHud.

fallbackFonts

Fonts tried in order for characters font lacks – for example a dynamic Korean, Japanese or Chinese font asset – after the font's own fallbacks and before the TMP Settings fallbacks. They are applied to a runtime copy of a static HUD font (such as the TMP default LiberationSans SDF), so neither that font asset nor the TMP Settings change. A dynamic HUD font ignores this list (one warning): give that font asset its own Fallback Font Assets instead.

[Tooltip("Fonts tried in order for characters the HUD font lacks (for example a dynamic CJK font asset). Applied to a runtime copy of a static HUD font; the font asset and the TMP Settings stay unchanged.")]
public List<TMP_FontAsset> fallbackFonts

Field Value

List<TMP_FontAsset>

TextMesh Pro font asset of the HUD, damage numbers and sample menus; empty uses the default font asset of the project's TMP Settings (LiberationSans SDF after importing the TMP Essential Resources).
