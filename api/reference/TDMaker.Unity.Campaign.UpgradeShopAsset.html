The permanent star-upgrade shop of a campaign: ordered tracks (columns) of ranks bought in order with earned stars. Purchases live in the save slot (GetUpgradeRank(string) by track key); a battle bakes the shop and the purchased ranks into a core UpgradeSnapshot (CreateSnapshot(Func<string, int>, int?)) that the simulation applies before anything spawns. Assign it to upgradeShop (the world map then shows a Shop button and every battle started while that campaign's slot is open applies it) or to a SimulationRunner directly. Edit it in Tools > 2D Tower Defense Maker > Upgrade Shop.
