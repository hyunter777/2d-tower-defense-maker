Class HudTexts

Namespace
TDMaker.Unity.Localization
Assembly
TDMaker.Unity.dll

Keys of every text the GameHud and the campaign screens show, and their built-in English texts (used when no table has a key). {0}, {1} ... are filled with numbers or names; keep them (in any order) when translating. The sample generator writes these texts into the English sample table, so a copy of that asset is a ready template.
