2D Tower Defense Maker API

Class NewLevelBuilder

Namespace
TDMaker.Editor
Assembly
TDMaker.Editor.dll

Headless core of Tools > 2D Tower Defense Maker > New Level: creates a level folder with a Level asset, a Wave Set, starter units (sample kit or Unit Workshop presets), a HUD theme and a sprite material, and a scene built by the sample scene builder (Simulation Runner, Level Authoring, one path across the frame, six build slots with rally points on the road, camera, Game HUD, Level View, audio and music players). The result passes the Project Validator and plays in the Dry Run: lost without towers, won with a defense. Usable from tests and -executeMethod; the window only collects the settings.
