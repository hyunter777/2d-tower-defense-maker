Class EntityView

Namespace
TDMaker.Unity.View
Assembly
TDMaker.Unity.dll

Pooled visual for one simulation entity: interpolated position, y-sorting, facing, optional health bar, hit flash, death fade, status-effect tint and icons, tower tier pips, projectile trail and orientation, hero death/return presentation, and an optional Animator driven with the standard parameters (Move bool, Speed float, Attack/Hit/Die triggers; missing parameters are skipped). Add it to custom prefabs to control sorting and the body renderer; it is added automatically otherwise.

[AddComponentMenu("2D Tower Defense Maker/Entity View")]
