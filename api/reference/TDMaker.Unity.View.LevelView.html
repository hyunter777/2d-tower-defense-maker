Class LevelView

Namespace
TDMaker.Unity.View
Assembly
TDMaker.Unity.dll

Draws level geometry for samples and prototypes: a generated ground texture (grass, roads that follow the lanes, rocks, tufts and trees), path entry/exit markers and stone build pads. Everything is procedural and deterministic.

[AddComponentMenu("2D Tower Defense Maker/Level View")]
