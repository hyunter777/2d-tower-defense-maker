Class AssetFormatUpgrade

Namespace
TDMaker.Editor

Finds maker assets (IVersionedAsset) written in an older data format and re-saves them in the current one, using the steps registered with AssetSchema. Assets saved by a newer package are never touched. The upgrade is a re-save and is not undoable; commit or back up the project first.
