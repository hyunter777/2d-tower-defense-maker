Automatic mine laying, baked into a DeploymentPlanDef with a TrapDef payload. Each activation picks one lane node of a level path inside the distance band around the producer (seeded, deterministic), reserves it, throws the mine (flight, landing, then the arm delay) and leaves a trap that bursts under the first eligible unit. The lifetime counts from the throw. Use it as an ability action (useMines); it fails, without a fallback spot, when no node fits.
